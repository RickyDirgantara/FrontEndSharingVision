# Sharing Vision Frontend
## Fitur

- **All Posts**: tab Published, Drafts, dan Trashed.
- Edit article, publish, save draft, dan pindahkan article ke trash.
- **Add New** untuk membuat article.
- **Preview** untuk melihat article publish dengan pagination.

## Menjalankan
npm install
npm run dev

Buka `http://localhost:5173`.

Untuk memakai URL backend berbeda, set `VITE_API_URL` sebelum menjalankan Vite. Saat development, `/article` otomatis diproxy ke `http://localhost:8080`.
